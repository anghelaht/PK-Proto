# Microsoft Fluent System Icons

These SVGs are selected regular-style icons from `@fluentui/svg-icons` version `1.1.341`.

- Source: https://github.com/microsoft/fluentui-system-icons
- License: MIT
- Package: https://www.npmjs.com/package/@fluentui/svg-icons

The files are vendored so this browser prototype renders the Microsoft iconography consistently on Windows and macOS without shipping the Windows-only Segoe Fluent Icons font.
